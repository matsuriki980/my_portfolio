skill

スキル

coding
デザインカンプを正確に読み取り、細部まで丁寧に再現できます。 HTML・CSS・JavaScriptを用いたWebサイト制作から、WordPressによるCMS構築まで対応可能です。
design
デザインの4原則を踏まえ、視認性が高く、目的の情報にたどり着きやすいWebサイトを設計できます。 また、Figmaなどのデザインツールを使用し、デザインカンプの確認・編集が可能です。

使用可能言語・ツール

HTML
セマンティックHTMLを用いた、文書構造を意識したマークアップが可能。
CSS
Flexbox・CSS Gridによるレイアウト構築、レスポンシブ対応が可能。
SCSS
ネスト・変数・ミックスイン・ファイル分割を用いたスタイル管理が可能。
JavaScript
DOM操作・イベント処理を用いた基本的なUIパーツの実装が可能。
WordPress
オリジナルテーマ制作、テンプレート分割、ループ処理、カスタム投稿タイプの実装
Figma / Photoshop
デザインカンプの読み取り、およびカンプをもとにしたWebページの実装が可能。
Git / Github
コミット、ブランチ管理、マージ、プルなどの基本操作が可能。

about

私について
